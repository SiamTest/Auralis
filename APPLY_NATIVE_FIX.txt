Complete Auralis project: selected-channel Library, music covers and channel photos

This ZIP contains the entire project, including a channel-only Telegram browser, an original Auralis app/installer icon, automatic stable release publication, the Windows COM shutdown fix, TDLib build caching, all source/build/packaging files and tests. Project files are at the ZIP root, without an extra parent folder.

1. Extract the ZIP.
2. Upload all extracted files and folders into the existing SiamTest/Auralis repository root, including .github, lib, windows, test, tool, third_party, native, docs, LICENSE, pubspec.yaml and pubspec.lock. Do not upload just the ZIP or treat a partial patch as the complete project.
3. Commit to main. The new workflow runs the checks/build/packaging, then automatically publishes a stable release if the version has not already been published. Re-running an old commit cannot apply this change.

Current version 0.1.3+4 produces stable tag/release v0.1.3. The tag is created at the exact tested commit. A release is explicitly NOT a prerelease, and remains a draft until uploaded asset checksums are verified. Main/manual-main and matching version-tag builds can publish; other branches and PRs cannot.

For later app updates, bump pubspec.yaml to a new stable version such as 0.1.4+5 and commit to main. Published versions and tags are never overwritten or moved. A push with the same published version skips release mutation. Installer updates require a newer stable version.
